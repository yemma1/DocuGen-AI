About DocuGen AI

Production-ready Python AST Code Documentation Platform

Project Overview

DocuGen AI is a full-stack developer tooling platform built using FastAPI, Python Abstract Syntax Tree (AST) static analysis, and an intelligent English translation engine. It provides developers, students, and code reviewers with immediate, deep insights into any Python source file without executing arbitrary code or exposing environments to security risks.

Technology Architecture

  • Backend: Python 3.11+, FastAPI (ASGI), Uvicorn, Pydantic v2
  • Static Analysis: Python standard ast module without code execution
  • Frontend: Modern HTML5, Responsive CSS3, Vanilla ES6 JavaScript
  • Design System: Custom SaaS Light-Blue Palette, Rounded Cards, Soft Shadows
  • Documentation Engine: Automated 10-Section Markdown Generator
  • API Specification: OpenAPI 3.1 / Swagger UI live at /docs

Security & Integrity

  • Safe Static Analysis: Source code is parsed into an AST tree; never executed.
  • Strict Upload Validation: Enforces .py extension and 5 MB size limits.
  • Sanitized Storage: Path traversal prevention and UUID-isolated file handling.
  • Zero Paid Dependency: Operates 100% offline via built-in rule-based explanation.
  • Optional AI Hook: Graceful OpenAI integration if API key is provided.
